# 0008: TOML for recipes

## Decision

⭐ **Recipes are TOML.**

## Problem

The format must be readable by a human reviewing a diff, parseable without
ambiguity, and editable by a bot without a line-based tool.

## Alternatives

| alternative | why rejected |
| --- | --- |
| ⛔ **YAML**, era 1 and 2's choice | ⚠ expressive; ⛔ ambiguous scalars (`no` becomes false, `1.10` becomes a float), significant whitespace that makes bot edits fragile, and multiple parsers that disagree |
| JSON | ⛔ no comments, and a recipe needs them |
| ⚠ a custom format | ⛔ a parser to write and to keep correct in every consumer |
| ⚠ Starlark or similar | ⛔ it is a programming language; that is [`0001-inert-recipes.md`](0001-inert-recipes.md) |
| ⭐ **TOML** | ⭐ chosen |

## Tradeoff

⭐ **Gained**: unambiguous scalars, comments, a small specification, and tables
that map onto the recipe's structure. ⭐ A bot can parse and re-serialise
without line editing.

⚠ **Cost**: less expressive than YAML. Deeply nested structures read worse.
Some things that were one clever YAML line become three explicit TOML ones.

## Evidence

⭐ **Observed**, era 2's `.github/workflows/update-checker.yaml`: the bot edits
YAML with `sed -i` and reimplements a YAML parser in roughly fifty lines of
`grep` and `sed` at lines 155 to 205 to extract a description. ⭐ That entire
class of code exists because the format resisted structured editing.

⭐ **Observed**, era 1: a package carries the key `licensen`, silently ignored
for the life of that package. ⛔ Unknown-key rejection is the fix and it is
independent of format; the typo is evidence that nothing was checking.

⭐ **Observed**, era 3 chose TOML for the same reasons after living with the
YAML tree.

## Consequences

- ⛔ Unknown keys are an error, not a warning.
  [`../format/build-manifest.md`](../format/build-manifest.md) §0.
- The bot writes only the generated release file and never touches the
  human-written recipe. [`../ci/update-automation.md`](../ci/update-automation.md) §6.1.
- Per-host overrides are tables rather than conditionals.

## Reversal

⚠ **Moderate.** A format change is mechanical for the data and would break
every external tool reading recipes. ⭐ Since only this project's tooling reads
them today, it is a conversion script and a version bump.
